## About

This project is a web-based implementation of the traditional **Simon** electronic memory game. It utilizes vanilla JavaScript to handle game logic, DOM manipulation, and event handling, providing a lightweight and responsive gaming experience without external frameworks.

##  Features

* **Classic Gameplay:** Replicates the traditional experience with four distinct colored buttons (Red, Green, Blue, Yellow).
* **Progressive Difficulty:** The sequence grows by one step after every successful round, making the game infinitely harder.
* **Visual & Audio Feedback:** Features clear button flashing animations and (optional) sound effects to indicate the sequence.
* **Score Tracking:** Real-time display of the current level and tracking of your highest score during the session.
* **Responsive Design:** Clean UI that works on desktop and adapts for simpler mobile play.

##  How to Play

The objective is simple: **repeat the sequence of flashing colors generated by the computer.**

1.  **Start the Game:** Press any key or click the **Start** button to begin level 1.
2.  **Watch the Sequence:** The game will flash a color (and play a sound). *Pay close attention!*
3.  **Repeat the Pattern:** Click the colored buttons in the **exact same order** shown by the computer.
4.  **Level Up:** If you get the sequence right, you advance to the next level, and a new color is added to the end of the sequence.
5.  **Game Over:** If you click the wrong color, the screen will flash red, and the game ends. Your score will be displayed, and you can restart to try again.

##  Technologies Used

* **HTML5:** Semantic structure of the game board.
* **CSS3:** Styling, animations (flash effects), and layout (Flexbox/Grid).
* **JavaScript (ES6+):** Game logic, event listeners, array manipulation for sequences, and DOM updates.

##  Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

You only need a modern web browser (Google Chrome, Firefox, Safari, or Edge) to play the game.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Sanju-1114/Simon-Says-Game.git
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd Simon-Says-Game
    ```

3.  **Launch the game:**
    * Locate the `index.html` file in the folder.
    * Double-click it to open it in your default browser.
    * *Alternatively, if using VS Code, you can use the "Live Server" extension.*

##  Project Structure

The project follows a modular structure to keep concerns separated:

| File | Description |
| :--- | :--- |
| **`index.html`** | The main markup file. Defines the game board, buttons, and layout structure. |
| **`style.css`** | Handles the visual presentation, button colors, flash animations, and responsiveness. |
| **`script.js`** | Contains the core game logic: sequence generation, user input validation, and level progression. |
